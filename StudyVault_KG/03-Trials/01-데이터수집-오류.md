## Trial-02: yfinance 구 ticker 404 오류

**현상**: AABA, ALXN, ATVI 등 상장폐지/합병 종목 → 빈 dict 반환  
**규모**: NASDAQ 1026개 중 약 514개(50%) 해당  
**해결**: try/except로 포착, 빈 set 할당 후 계속 진행

```python
for ticker in tickers:
    try:
        info = yf.Ticker(ticker).info
        sector = info.get('sector', '') or ''
    except Exception:
        sector = ''   # 실패해도 계속
```

**파급 영향**:
- Institutional KG: 443개 고립 노드
- Board KG: 1,002개 고립 노드 (97.7%)
- Sector KG: yfinance 방식 포기 → Wikidata dim24 대체

## Trial-03: Sector KG — yfinance 0 엣지 문제

**시도**: yfinance로 각 ticker의 industry 수집 → 같은 업종끼리 연결  
**결과**: 구 ticker 전부 industry = '' → 엣지 0개  
**해결**: Wikidata KG의 dim 24 (P452=industry) 직접 추출

```python
# 해결 코드
```

## Trial-04: Supply Chain — institutional 파일 복사본 문제

**현상**: `supply_chain.npy`와 `institutional.npy`가 byte-for-byte 동일  

```python
# 확인
inst  = np.load('NASDAQ_institutional_relation.npy')
supp  = np.load('NASDAQ_supply_chain_relation.npy')
np.array_equal(inst, supp)  # True → 버그!
```

**원인**: `build_supply_chain_kg.py`가 상대 경로로 저장 → 다른 위치에 출력됨  
실험 제출 시 institutional 파일을 supply_chain 경로로 복사함

**재구축 방법**:
```bash
# TRSR 원본에서 industry_ticker.json 추출
tar xzf relation.tar.gz relation/sector_industry/NASDAQ_industry_ticker.json

# 절대 경로로 실행
python build_supply_chain_kg.py
# → (1026, 1026, 1), 279,448 undirected edges, asymmetric
```

**예방책**: 항상 절대 경로 사용, `md5sum`으로 두 파일 동일성 사전 확인

```bash
md5sum NASDAQ_institutional_relation.npy NASDAQ_supply_chain_relation.npy
```

## Trial-06: LLM KG — 빈 캐시 파일 문제

**현상**: 첫 번째 API 키(401 Unauthorized) → 5개 ticker JSON이 빈 `{}` 로 저장됨  
**문제**: 캐시가 이미 존재하면 재호출 없이 빈 결과를 사용  

```python
# 버그가 있는 query_llm() 로직
def query_llm(ticker):
    cache_path = CACHE_DIR / f'{ticker}.json'
    if cache_path.exists():
        return json.loads(cache_path.read_text())  # 빈 {} 반환!
```

**해결**: 빈 캐시 수동 삭제 후 재실행

```bash
rm llm_cache/AABA.json llm_cache/AAPL.json ...
rm llm_cache/partial_0_5.npy
python build_llm_kg.py --start 0 --end 5   # 재실행
```

**예방책**: 캐시 로드 시 빈 dict 유효성 검사

```python
if cache_path.exists():
    data = json.loads(cache_path.read_text())
    if any(data.values()):   # 하나라도 값이 있으면 유효
        return data
    # 빈 캐시 → 삭제 후 재호출
    cache_path.unlink()
```
