## Trial-19: test IC에서 NaN 전파

**현상**: `np.mean(ic)` 반환값이 NaN → 전체 IC=NaN  
**원인**: SP500 test set에서 1일 all-zero mask 발생  
→ 474개 종목 전부 마스킹 → Pearson 상관 = NaN  
→ `np.mean([..., NaN]) = NaN`

```python
# 버그 (evaluation.py)
perf['IC']  = np.mean(ic)
perf['RIC'] = np.mean(ic) / (np.std(ic) + 1e-8)

# 수정
perf['IC']  = np.nanmean(ic)
perf['RIC'] = np.nanmean(ic) / (np.nanstd(ic) + 1e-8)
```

## Trial-20: 결과 파일 덮어쓰기 (market prefix 누락)

**현상**: SP500 실험 `gat_llm` 결과가 NASDAQ `gat_llm` 파일을 덮어씀  
**원인**: `run_name = f"{graph_type}_{kg_source}_seed{seed}"` — market 이름 포함 안 함

```python
# 버그 (main.py)
run_name = f"{config['graph_type']}_{config['kg_source']}_seed{config['seed']}"
# NASDAQ: "gat_llm_seed0" → 파일 생성
# SP500:  "gat_llm_seed0" → 같은 파일 덮어씀!

# 수정
market_prefix = config['market'] if config['market'] != 'NASDAQ' else ''
run_name = (f"{market_prefix}_" if market_prefix else '') + \
           f"{config['graph_type']}_{config['kg_source']}_seed{config['seed']}"
# NASDAQ: "gat_llm_seed0_daily_ic.npy"
# SP500:  "SP500_gat_llm_seed0_daily_ic.npy"
```
