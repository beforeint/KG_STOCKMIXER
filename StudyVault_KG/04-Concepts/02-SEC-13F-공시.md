## 13F란?

SEC(미국 증권거래위원회)가 요구하는 **분기별 기관투자자 보유 현황 공시**

- 대상: 운용자산 1억 달러 이상인 기관투자자
- 주기: 분기 종료 후 45일 이내
- 공시 내용: 보유 종목, 수량, 시장가치
- 공개 데이터: EDGAR에서 무료 열람 가능

## yfinance가 반환하는 것

```python
yf.Ticker("AAPL").institutional_holders
```

- 최근 분기 기준 **상위 N개** 기관만 반환 (전수가 아님)
- `Date Reported`가 기관마다 다를 수 있음 (보고 시기 차이)

## "동시에 보유"를 어떻게 아는가

동시에 실시간 확인하는 것이 **아니다**.  
데이터 수집 시점 기준 각 종목의 13F 신고 목록을 집합으로 만들어 교집합을 본다.

```
수집 시점: 2024년 10월

AAPL 13F: {Vanguard, BlackRock, State Street, ...}
MSFT 13F: {Vanguard, BlackRock, Fidelity, ...}

공통 기관: {Vanguard, BlackRock}
→ 같은 분기에 같은 기관이 두 종목을 모두 보유 중
```

---

## 한계 및 주의사항

| 한계 | 내용 |
|------|------|
| 상위 N개만 반환 | 소규모 기관투자자는 누락 |
| 구 ticker 데이터 없음 | 상장폐지 종목 → empty DataFrame |
| 기관명 문자열 불일치 | "Vanguard Group" vs "Vanguard Group Inc." → 다른 기관으로 처리 |
| 분기 지연 | 실제 보유 시점과 공시 시점 차이 (최대 45일) |
| 수집 시점 단일화 | KG 전체가 동일 분기 기준이지 않을 수 있음 |

---

## KG 관점에서의 의미

이 KG는 "정확한 동시 보유 관계"가 아니라  
**"같은 기관이 두 종목을 포트폴리오에 함께 담는 경향"**을 나타내는 근사 신호다.

동일 기관이 두 종목을 함께 보유한다 → 해당 기관이 두 종목을 연관 있다고 판단한다는 의미 → 두 종목 가격 움직임이 유사할 가능성.
