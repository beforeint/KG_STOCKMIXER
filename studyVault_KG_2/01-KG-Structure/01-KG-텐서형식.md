## 기본 형식

모든 KG 파일은 `numpy float32` 배열, 형식:

```
relation[i, j, r]
  i = 종목 인덱스 (source)
  j = 종목 인덱스 (target)
  r = 관계 타입 인덱스
  값 = 관계 강도 (0이면 엣지 없음)

shape: [S, S, R]
  S = 1026  (NASDAQ 종목 수)
  R = KG 종류에 따라 다름 (1 ~ 43)
```

저장: `np.save(OUTPUT_FILE, relation)` — `.npy` 포맷

---

## 대칭성

| KG | 대칭 여부 | 이유 |
|----|----------|------|
| Institutional | 대칭 | Jaccard는 방향 없음 |
| Sector | 대칭 | 같은 업종이면 양방향 동일 |
| Board | 대칭 | 공유 임원은 양방향 동일 |
| Supply Chain | **비대칭** | A→B 공급 ≠ B→A 공급 |
| LLM (기본) | 비대칭 | GPT 응답이 방향 포함 |
| LLM (--symmetry) | 대칭 | `np.maximum(mat, mat.T)` 적용 |
| News | 선택 | `--symmetry` 플래그로 결정 |
| Wikidata | 비대칭 | 원본 TRSR 그대로 |

## 대칭화 코드

```python
# 비대칭 → 대칭 변환 (merge 단계에서)
for r_idx in range(mat.shape[2]):
    mat[:, :, r_idx] = np.maximum(mat[:, :, r_idx], mat[:, :, r_idx].T)
```
