## Trial-24: 기간 불일치로 인한 비교 무효

**현상**: SP500 test (2020-2022) vs NASDAQ test (2016-2017) → 환경이 달라 cross-market 비교 의미 없음  
**해결**: SP500 config를 NASDAQ과 동일 캘린더로 재설정

```python
# 수정 전 (datasets/config.py)
'SP500': {
    'valid_index': 2000,   # 2020년대
    'test_index': 2200,
}

# 수정 후 (NASDAQ와 동일 날짜)
'SP500': {
    'valid_index': 886,    # 2015-11-19 (NASDAQ valid=756 동일 날짜)
    'test_index': 1138,    # 2016-11-18 (NASDAQ test=1008 동일 날짜)
}
```

> SP500 데이터는 2526일 → test=1138에서 시작해도 1388일 존재.  
> 비교 시 앞 237일만 사용하면 됨.

## Trial-26: SP500 LLM KG 역효과

**현상**: LLM V2 KG 적용 시 Low-Vol IC = -0.0062 (기존 대비 -273% 하락)  
**원인**: SP500에서 고립 노드 44.1% (209/474) → GAT 표현 붕괴

**대응 방안 (미구현)**:
- SP500에서는 LLM KG 제외하고 supply_chain or wikidata 사용
- 또는 고립 노드에 self-loop 추가 후 재실험
